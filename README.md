## Sobre este repositorio

Este repositorio reúne las entregas y la evolución del trabajo práctico realizado a lo largo de las 8 semanas de la materia **Introducción a la Ingeniería de Software Asistida por IA (IISAIA)**.

El objetivo central es documentar el proceso de desarrollo asistido por modelos de lenguaje (LLMs) mediante **Prompt Driven Development (PDD)**, registrando tanto los artefactos generados como los patrones de prompting e iteraciones sobre el estado.
